# Cycles of Care
### A Menstrual Rematriation Archive

An interactive biogeographical archive of traditional plant remedies for menstrual conditions. Each recipe documents ingredients, preparation, and use; each ingredient links to its GBIF species distribution map.

---

## Project structure

```
cycles-of-care/
├── public/
│   ├── data/
│   │   ├── ingredients.csv      ← ingredient/species database
│   │   ├── recipes.csv          ← recipe database (one row per ingredient)
│   │   └── geo/                 ← pre-fetched GBIF GeoJSON (generated by script)
│   └── img/
│       └── botanica/            ← botanical images (generated by script)
├── src/
│   ├── components/
│   │   ├── Archive.svelte       ← filterable recipe grid
│   │   ├── RecipeDetail.svelte  ← recipe view + overlap map
│   │   ├── IngredientDetail.svelte ← botanical card + species map
│   │   ├── MapView.svelte       ← shared Leaflet map (recipe/ingredient mode)
│   │   └── Header.svelte        ← nav + breadcrumb
│   ├── stores/
│   │   └── data.js              ← data loading, joins, derived stores
│   ├── py/
│   │   ├── gbif_images.py       ← pre-fetch botanical images from GBIF
│   │   └── gbif_occurrences.py  ← pre-fetch occurrence GeoJSON from GBIF
│   ├── App.svelte
│   ├── main.js
│   └── app.css
├── index.html
├── package.json
├── vite.config.js
└── svelte.config.js
```

## CSV format

### `ingredients.csv`

| column | description |
|---|---|
| `vernacular_name` | Common name(s), semicolon-separated, language in parentheses |
| `scientific_name` | Latin name — **join key** with recipes.csv |
| `used_parts` | Which part of the plant is used |
| `harvest` | Harvest instructions |
| `preservation` | Storage/drying notes |
| `desease` | Conditions treated, semicolon-separated |
| `GBIF` | Full GBIF species URL |
| `GBIF_id` | Numeric GBIF taxon key |

### `recipes.csv`

| column | description |
|---|---|
| `name` | Recipe ID (integer) — groups multiple rows into one recipe |
| `disease` | Condition(s) treated, semicolon-separated |
| `scientific_name` | **Join key** to ingredients.csv |
| `vernacular_name` | Vernacular name as used in source |
| `parts` | Parts used in this recipe |
| `quantity` | Quantity/weight |
| `type` | Preparation type: `infusion`, `decoction`, `tincture`, `poultice`, `oil` |
| `preparation` | Preparation instructions |
| `use` | How to use |
| `contraindications` | Warnings |
| `medical_recommendations` | Clinical notes |
| `source` | Bibliographic source |
| `country` | Country of origin |

## Setup

```bash
npm install
npm run dev
```

## Pre-processing (run once, or when you add new data)

```bash
# Fetch botanical images from GBIF → public/img/botanica/
python src/py/gbif_images.py

# Fetch occurrence GeoJSON → public/data/geo/  (optional, for offline maps)
python src/py/gbif_occurrences.py --limit 500
```

Requirements for Python scripts:
```bash
pip install requests pandas Pillow
```

## Deploy to GitHub Pages

Update `vite.config.js` and `package.json` with your repo name, then:

```bash
npm run deploy
```
